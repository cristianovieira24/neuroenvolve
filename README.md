# Neuroenvolve — proposta Crisora

Site estático com cinco cenas controladas pelo scroll, versão mobile, páginas da clínica e Baby Spa, e primeiro contacto pelo WhatsApp. O formulário apenas prepara o texto; o utilizador confirma o envio.

## Executar

```sh
python3 -m http.server 8080
```

Para GitHub Pages: branch main, pasta / (root). O index.html está na raiz.

Fotografias ilustrativas geradas para a proposta. Logo recuperada da identidade pública da clínica. Equipa atual, especialidades, horários e condições sujeitos à validação da Neuroenvolve. Fontes Newsreader e Hanken Grotesk, licenças OFL em assets.

Fontes de informação: [Notícias de Vila Real (inauguração, 2024)](https://noticiasdevilareal.sapo.pt/primeiro-baby-spa-do-distrito-abre-em-vila-real/) e [SuperConsciente (contacto e localização)](https://superconsciente.pt/).
